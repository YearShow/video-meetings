# PRD: AI-выжимка встречи (summary, action items, решения)

**Дата**: 2026-10-15
**Статус**: Draft

## Цель

После транскрибации файлов встречи пользователь по кнопке запускает обработку транскрипта через Claude Agent SDK и получает краткое резюме встречи, список задач (action items) с ответственными и список принятых решений. Это позволяет быстро понять итоги встречи, не читая полный транскрипт.

## Пользовательские сценарии

- Пользователь открывает встречу, у которой есть хотя бы один файл со статусом транскрибации «Готово» -> видит кнопку «Сформировать выжимку».
- Пользователь нажимает кнопку -> обработка стартует, кнопка блокируется, виден статус «В процессе».
- Обработка завершилась -> во встрече отображаются три блока: «Резюме», «Задачи», «Решения».
- В транскрипте назван ответственный за задачу -> у задачи указан ответственный; если не назван — задача показывается без ответственного.
- В транскрипте нет решений или задач -> соответствующий блок показывает пустое состояние («Решений не найдено»).
- Обработка завершилась ошибкой -> пользователь видит статус «Ошибка» с понятным сообщением и кнопку «Повторить».
- Пользователь закрыл страницу во время обработки и вернулся позже -> видит актуальный статус или готовый результат.
- Во встрече нет файлов с готовой транскрипцией -> кнопка недоступна, рядом пояснение причины.
- Участник встречи (не только владелец) открывает встречу -> видит готовую выжимку и может запустить или пересоздать её.
- Пользователь повторно нажимает кнопку при уже готовой выжимке -> результат пересоздаётся и заменяет предыдущий.

## В скоупе

- Ручной запуск обработки кнопкой на странице встречи; автоматического запуска нет.
- Источник данных — тексты транскрипций всех файлов встречи со статусом «Готово», объединённые в один запрос.
- Получение результата через Claude Agent SDK на сервере (`api`).
- Результат содержит:
  - summary — краткое резюме встречи;
  - список action items: описание задачи и ответственный (необязательное поле, заполняется только если назван в транскрипте);
  - список принятых решений (отдельным списком).
- Язык результата — русский.
- Сохранение результата в PostgreSQL; результат переживает перезапуск `api`.
- Статусы обработки: «Не запускалась», «В процессе», «Готово», «Ошибка».
- Повторный запуск (после ошибки и для пересоздания готовой выжимки); новый результат заменяет предыдущий.
- Отображение статуса и результата на странице встречи; статус обновляется без перезагрузки страницы.
- Права: запускать обработку и видеть результат могут все участники встречи (включая владельца).
- Обработка состояния после перезапуска сервера: прерванная обработка не остаётся навсегда в статусе «В процессе».
- Конфигурация доступа к Claude (ключ, модель) через переменные окружения; описание в документации.

## Не в скоупе

- Автоматический запуск обработки после окончания транскрибации.
- Редактирование summary, задач и решений пользователем.
- Отметка задач как выполненных, дедлайны, приоритеты, связь ответственных с аккаунтами пользователей.
- Хранение истории предыдущих версий выжимки.
- Выжимка по отдельному файлу; выбор файлов для обработки.
- Выбор языка, модели и промпта пользователем.
- Скачивание и экспорт выжимки, отправка по email или в мессенджеры, уведомления о завершении.
- Отмена обработки в процессе.
- Поиск по выжимкам.
- Обработка файлов без готовой транскрипции.

## Технические ограничения

- Транскрипт передаётся во внешний сервис Anthropic; это отличается от локальной транскрибации Whisper и должно быть отражено в документации.
- Объём транскрипта длинной встречи может превышать контекст модели; поведение в этом случае должно быть определённым (результат либо ошибка с понятным сообщением), а не тихая потеря части текста.
- Обработка занимает десятки секунд и более, поэтому HTTP-запрос запуска не должен ждать завершения.
- Ответ модели должен иметь строго определённую структуру (summary, задачи, решения); невалидный ответ считается ошибкой обработки.
- Ответственный указывается только если он явно назван в транскрипте; модель не должна его выдумывать. Качество зависит от качества транскрипции (модель Whisper `base`, возможны ошибки в именах).
- Результат и статус хранятся в БД; миграция Prisma обязательна.
- Один запуск на встречу одновременно: повторное нажатие во время обработки не создаёт параллельную обработку.
- Ключ доступа к Claude не попадает в репозиторий, логи и клиентский код.
- Существующие требования проекта сохраняются: JWT-авторизация, CQRS в модуле встреч, права доступа как у остальных данных встречи.

## Критерии готовности

- [ ] Во встрече с хотя бы одним файлом в статусе транскрибации «Готово» отображается кнопка «Сформировать выжимку»; без таких файлов кнопка недоступна с пояснением.
- [ ] Нажатие кнопки переводит обработку в статус «В процессе», кнопка блокируется, повторное нажатие не создаёт параллельный запуск (в том числе прямым вызовом API).
- [ ] По завершении на странице встречи отображаются summary, список задач и список решений, полученные от Claude через Agent SDK.
- [ ] У задачи показывается ответственный, если он назван в транскрипте; если не назван — задача отображается без ответственного, значение не выдумывается.
- [ ] Результат сохранён в БД и отображается после перезагрузки страницы и перезапуска `api`.
- [ ] Статус на странице обновляется без перезагрузки до перехода в «Готово» или «Ошибка».
- [ ] При ошибке (недоступность Claude, невалидный ответ, слишком длинный транскрипт) статус «Ошибка» показывает понятное сообщение, доступна кнопка «Повторить».
- [ ] Повторный запуск при готовой выжимке заменяет прежний результат новым.
- [ ] Если задач или решений нет, соответствующий блок показывает пустое состояние.
- [ ] Любой участник встречи (не только владелец) видит результат и может запустить обработку; пользователь вне встречи не получает доступ ни к статусу, ни к результату, и запуск прямым вызовом API возвращает 403.
- [ ] После перезапуска `api` обработка, прерванная на середине, не остаётся в статусе «В процессе».
- [ ] Ключ доступа к Claude задаётся переменной окружения, описан в `.env.example` и документации, не попадает в логи и клиентский код.
- [ ] Автотесты покрывают: запуск, защиту от параллельного запуска, сохранение результата, обработку ошибок, права доступа; для вызова Claude в тестах используется заглушка.
- [ ] Документация (`CLAUDE.md` корня и приложений, `README.md`) обновлена; `npm run lint`, `npm run typecheck`, `npm run test`, `npm run format:check` проходят.
