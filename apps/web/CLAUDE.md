# apps/web

Фронтенд на Next.js 16 (App Router), React 19, TypeScript, Tailwind 4. Исходники в `src/`, алиас импортов `@/*` → `src/*`.

@AGENTS.md

## Команды

Из корня репозитория: `npm run <script> -w apps/web`. Из этой папки — просто `npm run <script>`.

- `dev` — dev-сервер (`next dev`).
- `build` / `start` — production-сборка и запуск.
- `lint` / `lint:fix` — ESLint (`eslint.config.mjs`, на базе `eslint-config-next`).
- `typecheck` — `next typegen && tsc --noEmit`. `next typegen` нужен, чтобы появились глобальные типы вроде `LayoutProps`.

## Соглашения

- Роуты и layout лежат в `src/app/`. По умолчанию используйте серверные компоненты, `"use client"` только там, где он необходим.
- Стили через Tailwind, глобальные стили в `src/app/globals.css`.
- Форматирование делает корневой Prettier; не добавляйте локальный конфиг.
- Файлы `next-env.d.ts` и `.next/` генерируются, вручную не правьте.
